About this tool

This tool helps staff code services that were actually delivered and documented — it is a coding accuracy and revenue-capture aid, not a substitute for payer policy. CPT® codes are © the AMA. NCCI edits and payer rules change quarterly: when this tool and a current payer policy disagree, the payer policy wins. Log the outcome so the tool learns.
